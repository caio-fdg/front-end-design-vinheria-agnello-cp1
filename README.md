# Vinheria Agnello

Projeto desenvolvido para o **Checkpoint 1 da disciplina de Front-end Design**, do curso de Engenharia da Computação da FIAP.

O projeto consiste no desenvolvimento de um site para a **Vinheria Agnello**, uma empresa familiar que atua há mais de 15 anos com a venda de vinhos nacionais e internacionais.

A proposta é criar uma presença da Vinheria no ambiente digital, apresentando sua história, seus produtos e algumas informações sobre o mundo dos vinhos. O site também busca manter algumas características do atendimento realizado na loja física, principalmente através de conteúdos que possam ajudar o cliente durante a escolha de um vinho.

## Páginas do Projeto

O projeto possui cinco páginas:

- **Início:** apresenta a Vinheria Agnello e algumas informações sobre os principais tipos de vinhos.

- **Quem Somos:** apresenta um pouco da história da Vinheria, seu atendimento e os cuidados mantidos com seus produtos.

- **Sobre Vinhos:** apresenta diferentes tipos de vinhos, como são produzidos e alguns dos fatores que podem influenciar suas características, como o tipo de uva, clima, maturação e armazenamento.

- **Harmonização:** apresenta algumas sugestões de combinações entre vinhos e alimentos para diferentes refeições e ocasiões.

- **Fale Conosco:** possui um formulário que permite ao usuário entrar em contato com a Vinheria.

## Efeitos Visuais

Para o Checkpoint 02, foram adicionados efeitos CSS para tornar a navegação mais interativa e dinâmica:

- Pseudo-classes como `:hover`, `:focus`, `:focus-visible`, `:nth-child()`, `:last-child` e `:has()`.
- Pseudo-elementos `::first-letter`, `::after` e `::selection` para detalhes decorativos no título, menu e seleção de texto.
- Transições suaves em links, imagens, campos do formulário e botão de envio.
- Animação `@keyframes pulse` no botão de envio do formulário.
- Transformações com `scale()`, `translateY()` e `rotate()` em elementos interativos.

## Sobre o Desenvolvimento

Durante o desenvolvimento foram aplicados os conceitos apresentados nas aulas de Front-end Design, utilizando HTML para a estruturação das páginas e CSS para sua estilização.

O projeto utiliza elementos como títulos, parágrafos, listas, tabelas, formulário, imagens, vídeo e links entre as páginas. Também foram utilizadas tags semânticas para organizar o conteúdo e facilitar a estruturação do site.
